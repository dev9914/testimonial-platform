Embed Widget Demo

These iframes point to the Testimonial Platform embed endpoint. Start the frontend on http://localhost:5173 for them to render live. Each panel demonstrates a different widget configuration generated by the Widget Generator at /widget.

Light · Default

Theme=Light, show rating + company, 12px radius.

<iframe src="http://localhost:5173/embed?theme=light&rating=true&company=true&borderRadius=12" width="500" height="600" frameborder="0"></iframe>

Dark · Compact

Theme=Dark, hide company, 4px radius, narrower.

<iframe src="http://localhost:5173/embed?theme=dark&rating=true&company=false&borderRadius=4" width="360" height="600" frameborder="0"></iframe>

Minimal · Pill

Theme=Light, hide rating, big 32px border radius.

<iframe src="http://localhost:5173/embed?theme=light&rating=false&company=true&borderRadius=32" width="500" height="500" frameborder="0"></iframe>
